## Featured

### Skin Evidance

[![Skin Evidance](https://raw.githubusercontent.com/dipak90000/skin-evidance/main/docs/media/banner.svg)](https://github.com/dipak90000/skin-evidance)

A skincare brand storefront in Next.js — scroll-scrubbed hero, three product ranges,
segment browsing and a working cart across 30 static pages. Built end to end and
handed over to the client.

![Skin Evidance walkthrough](https://raw.githubusercontent.com/dipak90000/skin-evidance/main/docs/media/demo.gif)

<sub>Not publicly deployed — the client owns the domain and the launch date, so this
is a capture of the real build.</sub>

`Next.js` · `TypeScript` · `Tailwind` · `GSAP` · `Lenis` — **[see the repo →](https://github.com/dipak90000/skin-evidance)**
